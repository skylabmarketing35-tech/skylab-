SECTION 5 — JAVASCRIPT BEHAVIOR (script.js)
═══════════════════════════════════════════════════════════════════

All wrapped in IIFE with 'use strict'.

1. PRELOADER
   On window load → setTimeout 2200ms → add .hidden class to #preloader, 
   then call initObservers(), initAutoScrollers(), initGalleryReveal()

2. NAVBAR & MOBILE MENU
   - Scroll listener (passive): toggle .scrolled at scrollY > 60
   - Hamburger toggles mobile menu open/close
   - openMobile(): adds .active to hamburger & menu, sets aria, 
     body.classList.add('menu-open') (fades navbar via CSS), body overflow hidden
   - closeMobile(): reverses
   - Close on: X button, backdrop click, any mm-link click, mm-cta click, 
     Escape key
   - updateActiveNav(): compares scrollY+160 against each section's 
     offsetTop/offsetHeight, sets .active on matching .nav-link

3. SCROLL ANIMATIONS (initObservers)
   - IntersectionObserver on all .anim-in, threshold 0.08
   - Adds .visible class; honors data-delay attribute (×120ms)
   - Also calls initCounters()

4. COUNTERS (initCounters)
   - Targets .stat-num and .num-val elements
   - First: if text is "0" or empty, immediately set to data-target 
     (fallback so clones never show 0)
   - IntersectionObserver threshold 0.3 → countUp()
   - countUp(el, 0, target, dur): RAF-based, cubic ease-out
   - Refresh cloned counters after auto-scroll duplication

5. SERVICE FILTER
   - Listen for clicks on .srv-filter-btn
   - Toggle .active class, update aria-selected
   - Read data-filter value
   - For each .srv-card: hide (.filter-hide) if data-cat doesn't match 
     and filter ≠ 'all'
   - Reset track scroll to 0 smoothly

6. DRAG-SCROLL for .srv-track and .proj-track
   - mousedown/mousemove/mouseup/mouseleave events
   - Adjusts scrollLeft by delta × 1.5

7. STORY SCROLL
   - Duplicate innerHTML of #ssTrack for seamless loop
   - Pause animation-play-state on touchstart, resume on touchend

8. AUTO-SCROLL ENGINE (initAutoScroller)
   - RAF-based, translateX transform (NOT scrollLeft)
   - Each track: originalHTML + originalHTML (duplicated for seamless)
   - measure(): halfWidth = trackEl.scrollWidth / 2
   - tick(): position -= speed; if -position >= halfWidth, position += halfWidth
   - Pause on: mouseenter, touchstart, offscreen (IntersectionObserver)
   - Resume on: mouseleave, touchend (after 1.5s delay), onscreen
   - Speed values used:
       procTrack: 0.5
       expTrack:  0.5
       techTrack: 0.5
       certTrack: 0.4
       numTrack:  0.4
       indTrack:  0.5
       revTrack:  0.4
       galTrack:  0.5
   - Skipped entirely if prefers-reduced-motion

9. GALLERY REVEAL (initGalleryReveal)
   - IntersectionObserver on .gal-heading, .gal-sub (threshold 0.2) 
     → add .visible
   - IntersectionObserver on .gc-item (threshold 0.1, rootMargin 
     '0px 0px -60px 0px') → add .visible (staggered via CSS --gc-delay)

10. GALLERY LIGHTBOX
    - refreshGalCards(): 
        If window ≥1024px → use .gc-item elements (collage)
        Else → use .gal-card elements but SLICE TO FIRST HALF 
               (because auto-scroller duplicates them)
    - openLB(card): clone card's .gal-img or .gc-img into #lbImage, 
      set title/description from data attrs, show modal
    - closeLB(): hide, restore body scroll
    - navLB(dir): cycle index, reopen
    - Triggers: click on .gal-card or .gc-item, Enter/Space when focused, 
      prev/next buttons, Esc, Arrow keys, backdrop click

11. CONTACT FORM
    - Prevent default on submit
    - Validate Name (required, ≥2 chars), Phone (required, 
      /^[6-9]\d{9}$/), Email (optional, standard regex if filled)
    - showErr(id, msg) / clearErrors() helpers
    - Input listeners clear errors on typing
    - Phone input strips non-digits, slices to 10
    - On valid: submitBtn.classList.add('loading') → 1.6s → remove 
      loading, add 'success' → 3.5s → remove success, form.reset()

12. SMOOTH SCROLL
    - All a[href^="#"] → preventDefault, scrollTo target.offsetTop - 80 
      with behavior smooth

13. PREVENT HORIZONTAL OVERFLOW
    - body.style.overflowX = 'hidden'
    - documentElement.style.overflowX = 'hidden'

SECTION 7 — CRITICAL IMPLEMENTATION NOTES
═══════════════════════════════════════════════════════════════════

1. The auto-scroll engine DUPLICATES track content in JS. This means 
   any <img> in those tracks loads twice. Use loading="lazy" on 
   cert images to mitigate.

2. Counters (stat-num, num-val) appear BOTH in static sections (About 
   stats) and inside auto-scrolling tracks (Numbers section). The 
   refreshClonedCounters logic ensures clones show the final value 
   immediately rather than animating from 0 again.

3. Gallery has TWO completely separate DOM trees — .gal-collage for 
   desktop (static grid) and .gal-track for mobile (auto-scroll). 
   Both must be present in HTML; CSS media queries show/hide 
   appropriately.

4. Service filter cards and project cards are NOT auto-scrolled — 
   they're manual drag-scroll only, so they use native
